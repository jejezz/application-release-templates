# 제안: 고양이 앱 아이콘 (Sticker 글리프 대체)

상태: 제안 (시안 단계, 규약 미반영). 현재 규약은 [icons.md](../icons.md)의 Icons8 Sticker 글리프 + 그라데이션 판이다.

## 배경

앱의 정체성을 고양이로 삼고, 모든 앱 아이콘 배경에 같은 고양이가 들어가게 한다. Sticker 글리프를 고양이 위에 얹는 방식은 쓰지 않는다.

## 방식

- 고양이 얼굴은 모든 앱이 같다. 앱 구분은 **배경색**으로 한다.
- 배경 hue는 **앱 ID의 SHA-256 해시**에서 정한다. 같은 ID는 항상 같은 색이라 앱별 색을 기록·추적할 필요가 없다.
- 채도·명도는 고정해 시리즈의 통일감을 유지하고, 고양이(주황·노랑)와 겹치는 hue 구간(약 10°~72°)은 제외한다.
- 위→아래로 명도가 내려가는 그라데이션 + 고양이 뒤 옅은 원형 후광 + 고양이 그림자.
- 앱별 소품(예: 터미널의 `>_`)은 아직 넣지 않았다. 필요하면 레이어로 얹는다.

## 시안 결과 (daylight-terminal, portside)

| 앱 | hue |
|---|---|
| daylight-terminal | 143° (초록) |
| portside | 243° (보라·남색) |

- 128·64px에서는 표정이 읽히고, 32px에서는 줄무늬·수염이 사라지지만 눈·코·귀 실루엣으로 고양이임은 알아볼 수 있다.
- 16px는 노란 덩어리로만 보인다 → 작은 크기용 단순화 버전(굵은 수염, 진한 줄무늬)이 필요하다.

## 아직 안 한 것

- [icons.md](../icons.md)의 플랫폼별 규격(macOS 824px 판, Windows는 판 없이 글리프만, Linux 80% 등)에 맞춘 생성. 시안은 둥근 사각형 마스크를 직접 씌운 것이다.
- 작은 크기용 단순화 고양이.
- `generate_icons.py` 연동 (원본이 SVG가 아니라 PNG라서 `source_glyph.svg` 흐름과 다르다).

## 라이선스 주의

- 고양이 이미지는 Icons8에서 유료로 구입한 것이다. **이 저장소는 공개라서 원본 이미지와 그로부터 만든 PNG는 커밋하지 않았다.** 스크립트는 원본 경로를 인자로 받는다.
- 앱 아이콘·로고 용도 허용 여부, 수정 허용 여부, 표기 의무는 구입한 플랜의 Icons8 라이선스에서 확인해야 한다. 아직 확인하지 않았다.

## 시안 재현

```bash
pip3 install pillow
python3 common/tool/icon/cat_icon_mockup.py <고양이 원본> <출력 폴더> daylight-terminal portside
```
